# CODATHAN 🖥️

> **The Ultimate Coding Challenge Platform**  
> Built for Ayya Nadar Janaki Ammal College — Department of Computer Application

---

## 🚀 About

CODATHAN is a real-time competitive coding event platform featuring:
- 🔐 Lot-number based participant login
- ⏱️ Global event timer controlled by admin
- 🔒 Sequential round unlocking system
- 💻 In-browser C++ and Java code editor (powered by Monaco Editor)
- ✅ Automated hidden test case evaluation
- 🕵️ Anti-cheat tab-switch detection with real-time admin alerts
- 📊 Live leaderboard and results
- 📄 PDF report generation

## 🛠️ Tech Stack

- **Frontend**: React + Vite
- **Database**: Firebase Firestore (real-time)
- **Code Execution**: Wandbox API
- **Styling**: Custom CSS (Hacker Theme)
- **PDF**: jsPDF + jspdf-autotable

## ⚙️ Setup

```bash
npm install
npm run dev
```

## 🌐 Deployment

Deployed via Firebase Hosting or Vercel.
